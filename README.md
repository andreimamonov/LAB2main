# REST API Lab (FastAPI + PostgreSQL + Docker)

## Краткое описание проекта
Проект представляет собой REST API для управления сущностью `Item`. Реализованы все CRUD-операции, мягкое удаление (soft delete), пагинация, валидация входных данных, а также автоматическая документация Swagger UI. Приложение контейнеризировано с помощью Docker и использует PostgreSQL, SQLAlchemy, Alembic.

## Инструкция по запуску через `docker-compose up --build`

1. Убедитесь, что на компьютере установлен Docker Desktop.
2. Клонируйте репозиторий или скачайте проект.
3. В корневой папке проекта создайте файл `.env` на основе `.env.example` (см. следующий раздел).
4. Откройте терминал в папке проекта и выполните:
   ```bash
   docker-compose up --build
После успешного запуска API будет доступно по адресу: http://localhost:8000/docs

## Описание API (список эндпоинтов и параметров пагинации)
Метод	URL	Описание
GET	/items/	Получить список всех активных items (с пагинацией)
POST	/items/	Создать новый item
GET	/items/{id}	Получить один item по ID
PUT	/items/{id}	Полностью обновить item (все поля обязательны)
PATCH	/items/{id}	Частично обновить item (только переданные поля)
DELETE	/items/{id}	Мягко удалить item (остаётся в БД с меткой времени)
Параметры пагинации для GET /items/:

page (целое, ≥1, по умолчанию 1) – номер страницы

limit (целое, 1–100, по умолчанию 10) – количество записей на странице

## Пример запроса с пагинацией:

text
GET /items/?page=2&limit=5

## Инструкция по запуску миграций
Миграции управляются через Alembic. При запуске docker-compose up --build миграции применяются автоматически (благодаря entrypoint.sh). Если требуется выполнить миграции вручную:

bash
# Подключиться к контейнеру приложения
docker exec -it wp_labs_app bash

# Применить все миграции
alembic upgrade head

# (Опционально) Создать новую миграцию после изменения моделей
alembic revision --autogenerate -m "описание изменений"
Файлы миграций находятся в папке migrations/versions/. Все миграции закоммичены в репозиторий.
